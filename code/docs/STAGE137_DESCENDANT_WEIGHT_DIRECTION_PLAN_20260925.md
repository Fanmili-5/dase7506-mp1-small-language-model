# Stage137: one-model descendant weight direction

The qualified Stage85 mixture is 1.403024 BPB, while Stage92's static
order-five mixture is 1.401708 BPB but has narrow/unreliable CPU headroom.
The Stage136 successor route failed its prespecified quality gate. This
screen asks whether the fixed training displacement from the Stage71
average to its Stage92 distilled descendant improves the *same* static
Stage94-calibrated mixture without adding an inference branch. It is not a
new seed, architecture search, test-set probe, or additional ensemble.

Pin both existing averaged checkpoints and the train-derived order-five
count checkpoint by SHA-256. Require identical model configuration, tensor
names, shapes and dtypes. Predeclare five coefficient values along the
Stage71-to-Stage92 displacement: 0.75, 0.875, 1.0, 1.125, 1.25. Alpha 1.0
must reproduce the frozen 1.401708 BPB Stage92 reference within 2e-5.
At every alpha evaluate every validation target in GPU FP32, with the
unchanged train-unigram prior, temperature 1.125, copy-gate shift 0.25,
and order-five count weight 0.0625. Precompute the count target
probabilities once. Report all points, not just the minimum.

Only if this direction yields a meaningful gain (at least 0.0005 BPB over
Stage92, preferably below 1.4) may a *single* chosen weight set be
exported; the next gate is three-repeat official CPU timing plus RSS and
asset-size qualification. Until then Stage85 is the qualified fallback.
No test scores or submission will be generated by this experiment.

## Observed result

The source-pinned Windows RTX 3070 Ti screen completed all five full
validation evaluations (376,599 targets each). Alpha 1.0 reproduced the
Stage92 reference at **1.401707689 BPB**. Alphas 0.75, 0.875, 1.125 and
1.25 yielded respectively **1.401709201**, **1.401674674**, **1.401806513**
and **1.401969464 BPB**. The best prespecified point gains only
**0.000033013 BPB**, below the 0.0005 meaningful-gain gate and still above
1.4. Therefore no weights are exported or resource-qualified. The complete
raw evidence is in `../results/stage137-evidence/validation-gpu-fp32.json`.
This direction is closed; Stage85 remains the resource-qualified fallback.
No test scoring occurred.
